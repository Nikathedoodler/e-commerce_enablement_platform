# Creating Demo Videos

**Purpose:** Record short, focused videos demonstrating platform features  
**Target:** Pilot users who prefer self-paced learning  
**Format:** Short videos (2-5 minutes each) covering specific features

---

## 🎯 Video Strategy

Instead of one long demo, create **short, focused videos** for each feature:

1. **Easier to consume** - Users can watch what they need
2. **Easier to update** - Update individual videos when features change
3. **Better for reference** - Users can rewatch specific sections
4. **More engaging** - Shorter videos keep attention better

## 🎬 Recording Setup

### Tools Needed

**Screen Recording Software:**
- **Mac:** QuickTime (built-in) or ScreenFlow
- **Windows:** OBS Studio (free) or Camtasia
- **Cross-platform:** Loom, Screencast-O-Matic

**Audio:**
- Built-in microphone (usually fine)
- External microphone (better quality)
- Headset with mic (reduces background noise)

### Recording Settings

**Video Quality:**
- Resolution: 1920x1080 (1080p) minimum
- Frame rate: 30fps (60fps optional)
- Format: MP4 (most compatible)

**Audio:**
- Sample rate: 44.1kHz or 48kHz
- Bitrate: 128kbps minimum
- Test audio levels before recording

**Screen Setup:**
- Use full screen or specific window
- Hide personal information (bookmarks, notifications)
- Use a clean browser profile if possible

## 📝 Video Script Template

For each video, create a simple script:

```markdown
# Video: [Feature Name]

**Duration:** [X] minutes
**Goal:** Show users how to [specific task]

## Introduction (30 seconds)
- "In this video, I'll show you how to [feature]"
- "This helps you [benefit]"

## Main Content ([X] minutes)
1. Navigate to [page]
2. Show [feature]
3. Demonstrate [action]
4. Explain [benefit]

## Conclusion (30 seconds)
- "That's how you [feature]"
- "Next, check out the video on [related feature]"
```

## ✨ Recording Best Practices

### Do's ✅

- **Speak clearly and slowly** - Not too fast, not too slow
- **Show, don't just tell** - Actually click and interact
- **Use cursor highlights** - Move cursor to show what you're clicking
- **Pause between actions** - Give viewers time to process
- **Keep it focused** - One feature per video
- **Test first** - Do a quick run-through before recording
- **Edit out mistakes** - Cut out "ums" and errors (or re-record)

### Don'ts ❌

- **Don't rush** - Take your time explaining
- **Don't show everything** - Focus on the specific feature
- **Don't use filler words** - Avoid "um", "uh", "like"
- **Don't skip steps** - Show the complete process
- **Don't record in noisy environments** - Find a quiet space
- **Don't show personal info** - Hide bookmarks, emails, etc.

## 📋 Video Production Workflow

### Step 1: Prepare (5 minutes)
1. Load demo data
2. Open the feature you're recording
3. Test the flow once
4. Prepare brief notes/script

### Step 2: Record (10-15 minutes)
1. Start recording
2. Follow your script/notes
3. Do the full demonstration
4. Stop recording

### Step 3: Review (5 minutes)
1. Watch the recording
2. Note any mistakes or issues
3. Decide if you need to re-record

### Step 4: Edit (Optional, 10-20 minutes)
1. Cut out mistakes
2. Add intro/outro if desired
3. Add text overlays for key points (optional)
4. Export final video

### Step 5: Upload & Share (5 minutes)
1. Upload to YouTube (unlisted) or Vimeo
2. Or host on your own platform
3. Add to documentation
4. Share link with pilot users

## 📦 Video Hosting Options

### Option 1: YouTube (Recommended)
- **Pros:** Free, easy sharing, good quality
- **Cons:** Public (unless unlisted)
- **Setup:** Create unlisted videos, share links

### Option 2: Vimeo
- **Pros:** Professional, good quality, privacy controls
- **Cons:** Free plan has limits
- **Setup:** Upload, set privacy, share links

### Option 3: Self-Hosted
- **Pros:** Full control, no platform restrictions
- **Cons:** Requires hosting, bandwidth costs
- **Setup:** Upload to your server/CDN

### Option 4: Loom
- **Pros:** Easy recording, built-in sharing
- **Cons:** Free plan has limits
- **Setup:** Record directly, share link

## 💡 Pro Tips

1. **Record in batches** - Do all recordings in one session
2. **Keep it natural** - Don't over-script, be conversational
3. **Show real data** - Use the demo assets you created
4. **Add timestamps** - In video description, add timestamps for key sections
5. **Create a playlist** - Group related videos together
6. **Update as needed** - When features change, update videos
