## Email Best Practices

### Do's ✅
- Personalize with user's first name
- Include clear next steps
- Provide links to resources
- Set expectations (support response time, pilot timeline)
- Make it easy to get help

### Don'ts ❌
- Don't overwhelm with too much information
- Don't use technical jargon
- Don't forget to include login credentials/reset link
- Don't skip contact information

---

## When to Send

**Timing:**
- **Immediately** after account creation
- **Before** scheduled demo/onboarding call (if applicable)
- **Within 24 hours** of pilot user signing up

**Follow-up:**
- Send a check-in email after 3-5 days
- Ask how it's going and if they need help
- Request initial feedback
